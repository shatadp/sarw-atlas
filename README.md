# SARW Atlas

India Higher Education & Skills Landscape — a visuals-first, state-level interactive
map and dashboard built by SARW Labs for founder situational awareness, published
in public as a SARW credibility asset.

## Start here (for Claude Code)
Read the docs in order before building:
1. `docs/01_PRD.md` — what we're building and for whom
2. `docs/02_ARCHITECTURE.md` — the static-now/backend-later split + stack
3. `docs/03_DATA_SPEC.md` — the data, its grain, and its hard limits
4. `docs/04_BUILD_ROADMAP.md` — phased plan with validation gates

## What's already done
- `data-pipeline/extracted/` — validated AISHE 2021-22 CSVs (6 tables, all checked
  against published national totals).
- `data-pipeline/scripts/` — the Python extractors that produced them.

## V1 scope (locked)
- **Audience:** the founder first (public can view).
- **Branding:** SARW Labs.
- **Geography:** state-level (districts later).
- **Surface:** interactive India map + linked charts + founder's-read narrative.
- **Host:** GitHub Pages (static), architected to add an AI/streaming backend later.

## Hard rule
Discipline data is NATIONAL only — AISHE never crosses discipline with geography.
The UI must respect this (see docs/03_DATA_SPEC.md §4).

## Folder structure (must match this for the docs/roadmap to work)
```
sarw-atlas/
├── README.md
├── docs/            01_PRD · 02_ARCHITECTURE · 03_DATA_SPEC · 04_BUILD_ROADMAP
├── data-pipeline/
│   ├── extracted/   7 validated CSVs + DATA_DICTIONARY.md
│   └── scripts/     extractors + build_json.py (CSV→JSON)
└── public/data/     states.json + disciplines.json  (generated by build_json.py)
```
Regenerate JSON anytime with:  `python data-pipeline/scripts/build_json.py`
